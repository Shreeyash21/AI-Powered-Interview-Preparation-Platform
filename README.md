# 🚀 AI-Powered Interview Preparation Platform

An advanced AI-driven interview preparation platform that helps students and professionals prepare for real-world technical and HR interviews through intelligent mock interviews, voice interaction, coding assessments, resume analysis, and emotion detection.

The platform simulates realistic interview environments using Artificial Intelligence, Computer Vision, Speech Processing, and NLP technologies to provide personalized interview experiences, real-time behavioral analysis, and detailed performance feedback.

# ⚙️ Installation & Setup

## 1️⃣ Clone Repository

```bash
git clone https://github.com/your-username/AI-Interview-Preparation-Platform.git
```

## 2️⃣ Navigate to Project Folder

```bash
cd AI-Interview-Preparation-Platform
```

---

# 🔥 Frontend Setup

```bash
cd frontend
npm install
npm start
```

---

# 🔥 Backend Setup

```bash
cd backend
pip install -r requirements.txt
python app.py
```

---

# 🔑 Environment Variables

Create a `.env` file inside the backend folder.

```env
OPENAI_API_KEY=your_api_key
GEMINI_API_KEY=your_api_key
MONGODB_URI=your_database_url
JWT_SECRET=your_secret_key
```
